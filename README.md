# SCT_DS_1 - Data Visualization

This project is part of the Data Science Internship at SkillCraft Technology.

## Objective
To create visualizations using bar charts and histograms for understanding data distribution.

## Dataset
Titanic Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Visualizations Created
- Gender Distribution
- Age Distribution
- Passenger Class Distribution
- Survival Distribution
- Fare Distribution

## Key Insights
- Most passengers were male
- Majority of passengers belonged to Class 3
- Most passengers were aged between 20–40 years
